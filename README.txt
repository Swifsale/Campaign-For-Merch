SWIFI TOTEM — PANDUAN SINGKAT

1. Ekstrak folder "swifi-totem" dari ZIP.
2. Buka folder tersebut.
3. Klik dua kali index.html. Website berjalan langsung di browser, tanpa server dan tanpa instalasi.
4. Untuk tampilan totem, tekan F11 agar browser fullscreen.

PENGATURAN WAJIB SEBELUM DIPAKAI
- Buka script.js menggunakan Notepad atau editor teks.
- Cari: const INSTAGRAM_HANDLE = "@USERNAME_SWIFA";
- Ganti @USERNAME_SWIFA dengan username Instagram resmi yang benar.
- Simpan file.

PERILAKU
- Lima pose SWIFI berganti otomatis setiap 10 detik.
- Tampilan dirancang untuk layar portrait 9:16.
- Foto karakter tetap menggunakan file PNG asli yang disertakan dalam folder assets.
- Tidak memerlukan koneksi internet untuk menjalankan animasi. Font online hanya peningkatan tampilan; jika offline, browser memakai font cadangan.

CATATAN
Sebelum acara, uji pada resolusi layar totem yang sebenarnya dan pastikan skala browser 100%.

PEMBARUAN TAMPILAN
- Area judul, karakter, dan informasi hadiah dipisahkan agar tidak saling menutupi.
- Dialog SWIFI sekarang tampil sebagai speech bubble di samping karakter.
- Teks dialog ikut berubah setiap kali pose SWIFI berganti.

UPDATE MEKANISME PROMO
- Tulisan hadiah menggunakan "GOODYBAG" (tanpa spasi).
- Syarat Instagram: upload ke Instagram Story dan tag @swifasia.
- Tidak ada kewajiban membuat feed post.
- Speech bubble diposisikan dengan batas aman agar tidak terpotong layar.
